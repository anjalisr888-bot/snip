# snip

A URL shortener with click analytics, built with FastAPI and PostgreSQL.

Short codes are generated by base62-encoding the database ID, which
guarantees unique codes with no collisions. A custom LRU cache and a
custom rate limiter are planned next.

## Features
- Custom aliases (409 if taken, validated, reserved words blocked)
- Shorten URLs with auto-generated base62 codes
- Optional link expiry (`expires_in_days`, 410 when expired)
- Click analytics: total clicks, clicks per day, top referrers (`GET /stats/{code}`)

## Tech stack
- Python, FastAPI
- PostgreSQL (run with Docker)
- pytest

## Run locally
1. `docker compose up -d`
2. `pip install -r requirements.txt`
3. `uvicorn app.main:app --reload`
4. Open http://localhost:8000/docs
## Benchmark
Load test with Locust: 20 users, 30 seconds, local machine, redirect endpoint only.

| Setup | Requests/s | Median | 95th percentile |
|---|---|---|---|
| Without cache | 111 | 87 ms | 150 ms |
| With custom LRU cache | 194 | 35 ms | 58 ms |

The LRU cache is about 2.5x faster at the median and handles about 75% more
requests per second. Every redirect still writes a click row, so the cache only
removes the lookup query.
