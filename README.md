# snip

A URL shortener with click analytics, built with FastAPI and PostgreSQL.

Short codes are generated by base62-encoding the database ID, which
guarantees unique codes with no collisions. A custom LRU cache and a
custom rate limiter are planned next.

## Tech stack
- Python, FastAPI
- PostgreSQL (run with Docker)
- pytest

## Run locally
1. `docker compose up -d`
2. `pip install -r requirements.txt`
3. `uvicorn app.main:app --reload`
4. Open http://localhost:8000/docs
